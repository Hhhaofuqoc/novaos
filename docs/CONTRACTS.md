# NovaOS 0.1.0-alpha integration contracts

Debian 13 trixie. Mobile Lite: Termux host -> proot-distro Debian alias novaos -> non-root nova user -> dbus-run-session startxfce4 through Termux:X11. No systemd inside PRoot. Desktop Lite: XFCE; Desktop full: Plasma. Core apps: Python3 GTK3 + GStreamer. No web UI.

Repository root /workspace/novaos. Install prefix /usr, assets /usr/share/novaos, Python module /usr/lib/python3/dist-packages/novaos. Source package applications/novaos. Main command novaos (Python -m novaos); subcommands settings, monitor, welcome, notes, music, profile [auto|lite|balanced|ultra], theme [dark|light], session-init, diagnostics. NovaMusic module applications/novaos/music.py exports main(). Music assets music/generated, compositions source music/generate.py. Python dependencies from Debian APT only.

Core installer installers/install-system.sh [--destdir PATH] installs sources and assets without apt; package builder scripts/build-deb.sh creates dist/novaos-desktop_0.1.0_all.deb. Common dependency lists desktop/packages-lite.txt, desktop/packages-plasma.txt. Session integration via /etc/xdg/autostart/novaos-session.desktop runs novaos session-init. Theme initializer themes/apply-xfce.sh [lite|balanced|ultra] [dark|light], reads installed /usr/share/novaos assets or NOVAOS_ASSETS env. Must preserve existing user settings unless explicit apply. Themes under themes/NovaOS-Dark and themes/NovaOS-Light. Wallpaper wallpapers/novaos-desktop.svg and novaos-mobile.svg; PNG renders optional. Commands novaos-* wrappers may forward to novaos subcommands. Music player reads /usr/share/novaos/music/generated/manifest.json, env NOVAOS_ASSETS overrides /usr/share/novaos for source tests. Files/terminal/browser/editor/process integrations use Thunar, xfce4-terminal, firefox-esr, mousepad, xfce4-taskmanager. Store/updater use Synaptic on desktop; mobile safe terminal apt with explicit confirmation.

Tests: python3 -m unittest discover -s tests -v. Local Python tests must not require GTK except separate integration tests. Genuine installed GTK tests via Debian container + Xvfb where available. Every agent owns tests for its components. Root handles README, overall docs, common installer, core Python apps, final validation/artifacts. Agents must not claim Android/ISO boot validation unless actually performed. Do not commit; root commits coherent final state.
